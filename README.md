# 🧞 FileGenie

FileGenie is an AI-powered file organizer that automatically categorizes and organizes your files using CLIP embeddings and a vector database.

> **Repository:** https://github.com/Gal1lioDev/FileGenie :contentReference[oaicite:0]{index=0}

---

# Features

- 📂 Intelligent file organization
- 🖼️ Image understanding using CLIP
- 🧠 Semantic similarity search with vector embeddings
- ⚡ Fast local organization
- ☁️ CLIP inference hosted from Google Colab

---

# Prerequisites

Before running FileGenie, make sure you have:

- Python 3.10 or newer
- A Google account (for Google Colab)
- Internet connection

---

# Installation

Clone the repository:

```bash
git clone https://github.com/Gal1lioDev/FileGenie.git
cd FileGenie
```

Install the required packages:

```bash
pip install -r requirements.txt
```

---

# Running the CLIP Server

FileGenie communicates with a CLIP server running in Google Colab.

## Step 1

Open the notebook:

```
Understanding_CLIP.ipynb
```

Upload it to **Google Colab**.

---

## Step 2

Run every cell from top to bottom.

The notebook will automatically install all required dependencies.

---

## Step 3

Run the cell named:

```
Start Server
```

After a few seconds, the notebook will display a Cloudflare Tunnel URL similar to:

```
https://example-name.trycloudflare.com
```

**Do not close the notebook.**

The Colab runtime must remain running while using FileGenie.

---

# Configure FileGenie

Open:

```
config.py
```

Locate:

```python
DEFAULT_URL = ""
```

Replace it with the Cloudflare URL generated by the notebook.

Example:

```python
DEFAULT_URL = "https://example-name.trycloudflare.com"
```

Save the file.

> **Note:** Every time you start a new Colab session, Cloudflare generates a new URL. You'll need to update `DEFAULT_URL` with the new address.

---

# Launch FileGenie

Once the CLIP server is running and `DEFAULT_URL` has been updated:

```bash
python SmartFolder.py
```

That's it! 🎉

FileGenie is now connected to your Colab-hosted CLIP server and ready to organize your files.

# Troubleshooting

### Unable to connect to the server

- Make sure the Google Colab notebook is still running.
- Verify that you executed the **Start Server** cell.
- Confirm that `DEFAULT_URL` exactly matches the Cloudflare URL shown in Colab.

---

### ModuleNotFoundError

Install the required packages again:

```bash
pip install -r requirements.txt
```

---

### The Cloudflare URL changed

This is expected.

Every new Colab runtime creates a new URL. Simply copy the new `https://*.trycloudflare.com` address and replace the value of `DEFAULT_URL` in `config.py`.
